## ✨ Features

- 🎨 **Dark & Light Mode** — Smooth theme toggle with system preference detection
- ⚡ **Live GitHub Stats** — Real-time repositories, contributions & coding years fetched from GitHub API
- 🎬 **Smooth Animations** — Page transitions & scroll-triggered animations powered by Framer Motion
- 📱 **Fully Responsive** — Optimized for desktop, tablet, and mobile devices
- 📬 **Contact Form** — Integrated email delivery via EmailJS
- 🔍 **SEO Optimized** — Proper meta tags, semantic HTML, and structured heading hierarchy
- 🧭 **Smooth Scrolling Navigation** — Fixed navbar with active section highlighting
- ✍️ **Typewriter Effect** — Dynamic role display in the hero section

## 🚀 Getting Started

### Prerequisites

- **Node.js** (v18 or higher)
- **npm** or **yarn**

### Installation

```bash
# Clone the repository
git clone https://github.com/MrMajharul/Portfolio.git

# Navigate to the project
cd Portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be running at `http://localhost:5173`

### Build for Production

```bash
npm run build
```

## 📊 Live GitHub Stats Integration

The portfolio fetches **real-time data** from the GitHub API:

- **Repositories** — Public repo count from `api.github.com`
- **Contributions** — Annual contribution count via GitHub Contributions API
- **Years Coding** — Calculated from GitHub account creation date
- **Live Projects** — Manually maintained count

Falls back to hardcoded values if the API is unavailable.
